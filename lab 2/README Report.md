# Лабораторная: Продакшн-образы Docker

**Цель:** собрать production-образ для мини-сервиса на Flask так, чтобы он был:
- маленький (**< 150 MB**) ✅
- безопасный (**не root**) ✅
- с **HEALTHCHECK** ✅
- корректно завершался по **SIGTERM** ✅
- умел работать при `--read-only`✅
- принимал конфиг через переменные окружения **без пересборки**✅

В отличие от «наивной» сборки, этот образ собран через multi-stage. Т.е весь кэш `pip` и сборочные утилиты остались на первом этапе (`builder`), а в финальный контейнер на базе лёгкого `alpine` перенесены только готовые библиотеки и сам код. Благодаря этому размер образа составил всего 109 МБ.
Для безопасности приложение крутится от имени обычного пользователя `abuser`, а не от `root`. Чтобы сервер не падал при запуске с флагом `--read-only`, временные файлы Gunicorn перенаправлены в оперативную память (`/dev/shm`). Также использован `HEALTHCHECK`, чтобы Docker мог проверять доступность страницы.
